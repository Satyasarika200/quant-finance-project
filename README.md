JP Morgan Quant Finance Project

1. Overview

This project was completed as part of the JP Morgan virtual experience program. It focuses on solving real-world financial problems using data analysis and quantitative techniques.

2. Tools & Technologies

* Python
* Pandas
* NumPy
* Jupyter Notebook

3. Tasks Covered

* Task 1: Data Analysis
* Task 2: Financial Modeling
* Task 3: Risk Analysis
* Task 4: Visualization

4. How to Run

1. Clone the repository
2. Open the `.ipynb` files in Jupyter Notebook
3. Run the cells step by step

5. Outcome

Gained hands-on experience in quantitative finance and data-driven decision making.
